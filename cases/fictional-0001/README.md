# Fictional Case 0001 / 架空事例0001

This entirely fictional case shows why a chronological sequence should not be presented as a causal chain.

この完全に架空の事例は、時系列を因果の連鎖として扱わないためのものです。

| Time | Recorded event | Source | Status |
| --- | --- | --- | --- |
| 09:00 | A team notes two alternatives. | fictional meeting note | recorded |
| 10:00 | A prototype check is recorded. | fictional test log | recorded |
| 11:00 | One alternative is removed from the next draft. | fictional change log | recorded |

The record establishes order. It does **not** establish why the alternative was removed. “The prototype check caused the removal” is an inference, not a recorded fact.

記録は順序を示します。しかし、なぜ案が除かれたかは示しません。「試作確認が除外を引き起こした」は、記録された事実ではなく推測です。

## Residual / 残余

No independent decision rationale is available. A later account could support, qualify, or contradict the proposed causal link.

独立した判断理由の記録はありません。後から得られる説明は、因果リンクを支持・限定・反証しえます。
