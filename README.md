# Decision Trace Casebook / 意思決定トレース事例集

Evidence-bounded case studies that separate recorded events, chronology, and causal inference.

記録された出来事、時系列、因果推測を分けたまま意思決定を読み直すための事例集です。

## Current release

The first source case is explicitly `n=1` and local-only. This repository contains a fictional reproduction case and a reusable template—not the raw workflow record.

最初の事例は明示的に `n=1`・ローカル限定です。ここには生の作業記録ではなく、架空の再現ケースと再利用可能なテンプレートを置いています。

## Included / 収録物

- `template/` — a record format that keeps event time, evidence, and inference separate
- `cases/fictional-0001/` — a fully fictional worked example

The example is designed to be inspected or adapted. It does not report a real organization, person, or decision.

例は読んだり改変したりするためのものです。実在する組織・人物・判断を報告するものではありません。

## Not a claim

A reconstructed sequence does not prove causal necessity or establish a general rule.

復元した順序は因果必然性や一般則の証明ではありません。
Bilingual, evidence-bounded case studies for reconstructing decisions without turning inference into fact.
